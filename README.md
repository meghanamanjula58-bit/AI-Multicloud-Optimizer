# AI-Based Multi-Cloud Resource Management and Optimization System

## About the Project
This project provides a centralized dashboard to monitor and analyze cloud resources across AWS, Microsoft Azure and Google Cloud.

## Project Features
- Multi-cloud dashboard
- CPU, memory and storage monitoring
- Cloud cost analysis
- Gemini AI Assistant
- Resource optimization recommendations
- Cloud reports and CSV downloads
- Historical data storage

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- SQLite
- Google Gemini API

## How to Run

Install the required packages:

pip install -r requirements.txt

Start the application:

streamlit run app.py

## Note
The current dashboard uses sample cloud data. Live cloud integrations are not yet configured.
